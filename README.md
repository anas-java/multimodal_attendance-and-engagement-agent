# Multimodal Attendance & Engagement Agent

Local-first educational prototype using Python, OpenCV, MediaPipe, audio signal processing, Pandas and Streamlit.

## Implemented
- Recorded video upload and frame sampling.
- OpenCV Haar-cascade face detection.
- Anonymous, session-local IoU-based track association with a missed-detection expiry window.
- Sustained-presence duration estimate and manual-review attendance CSV.
- Optional MediaPipe Face Mesh plus OpenCV `solvePnP` approximate yaw/pitch/roll estimates.
- Frame-difference motion index and visual timeline.
- Audio decoding (soundfile; PCM WAV fallback), RMS energy, zero-crossing rate, and heuristic speech-like windows.
- Relative-time session-level video/audio timeline fusion.
- Rule-based teaching suggestions and downloadable JSON report.
- Streamlit dashboard, snapshot test, local CSV records and delete/download controls.
- Temporary media cleanup and face-blurred preview.

## Requirements
Python 3.10 or 3.11 recommended. MediaPipe wheels vary by OS/Python; Python 3.11 is a good starting point.

## Install on Windows
Extract the ZIP, open PowerShell in the project folder, then:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

If activation is blocked:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Open `http://localhost:8501` when Streamlit prints the local URL. Do not expose the app to the public internet.

## macOS/Linux
```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

## Workflow
1. Open Video & attendance; upload a short test clip and choose the minimum presence duration.
2. Run analysis and inspect track durations. Track IDs are temporary, not names.
3. Save attendance only after reviewing the output.
4. Upload the corresponding audio separately in Audio analysis.
5. Open Multimodal insights to view session-level summary, suggested teaching actions, and a downloadable JSON report.
6. Use Records to download or delete local attendance CSV.

## Design details
- **Face detection:** OpenCV Haar cascade. It may miss profiles/poorly lit faces or produce false positives.
- **Tracking:** greedy IoU matching. This is deliberately simple and can split/merge tracks; it is not a re-identification algorithm.
- **Head pose:** MediaPipe Face Mesh landmarks plus a generic 3-D facial model in `solvePnP`. Camera calibration and subject geometry are not personalized, so angles are approximate. The current implementation estimates pose from the first detected mesh in a frame; multi-person pose association is not production-grade.
- **Visual motion:** mean frame difference is a camera/scene motion proxy, not attention.
- **Audio:** RMS and zero-crossing rate provide rough activity and speech-like heuristics. They cannot reliably distinguish speech from noise and do not transcribe speech, identify speakers, or link speech to a person.
- **Fusion:** video and audio are aligned by relative time from file start and rounded into half-second buckets. The user must ensure the recordings are synchronized. Suggestions are rule-based and not generated by an external LLM.
- **Attendance:** duration is time between first and last matched detection; intermittent gaps can overestimate presence. Every record is flagged for human review.

## Privacy and safety
- Obtain informed consent and follow institution policies and applicable law before recording learners.
- Prefer synthetic/demo data or consenting adults for development.
- Processing stays on the local machine; no API or cloud upload is performed.
- Temporary uploaded video is deleted after processing; temporary audio files are deleted by the analyzer.
- Local CSV attendance is stored only when the save button is pressed. Local disk storage is not encrypted by this app.
- Faces are blurred in the preview, but original video is held in memory during processing and blurring is not a complete anonymity guarantee.
- Do not use outputs for grading, discipline, diagnosis, disability inference, emotion detection, or other high-stakes decisions.
- Provide a non-camera alternative and a way to challenge/correct attendance.
- Restrict device access, define a retention period, and delete records when no longer needed.

## Testing checklist
- One person in frame for longer than threshold; then a brief walk-by shorter than threshold.
- Multiple people; note track split/merge behaviour.
- Low light, profile faces, occlusion, camera shake and different distances.
- A silent WAV, speech recording, and noisy recording; verify noise can look active.
- Different video/audio lengths; check the warning in session insights.
- Save, download and delete attendance CSV.
- Before any real deployment, compare with manually annotated ground truth and document precision/recall and error rates.

## Troubleshooting
- Video codec error: re-encode as MP4/H.264 or AVI.
- MediaPipe install failure: use Python 3.11 and install in a fresh virtual environment; the rest of the app runs without head-pose estimates if MediaPipe cannot import.
- No faces: use a frontal, well-lit clip and ensure faces occupy enough pixels.
- Audio decoder failure: use PCM WAV.
- Port busy: `streamlit run app.py --server.port 8502`.
